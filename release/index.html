Nyx Monitor @VERSION@

Un compañero para el escritorio de GNOME 50 (Wayland) con CPU, RAM y GPU, y personajes a elegir.

Para instalarlo, abre una terminal y pega:

curl --proto '=https' -fsSL https://nyx.majomaken.dev/get.sh | bash

Luego cierra sesión y vuelve a entrar. Las actualizaciones llegan solas como aviso; se instalan desde el engranaje del widget, página «Actualizaciones», o con nyx-monitor-update install.
